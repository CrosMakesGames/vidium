Your streams, your player, your machine.

Vidium is a fully custom streaming player built on the vidsrc resolution chain. One zero-dependency Node server, no upstream iframes, community skip-intro timings, and a file you can host anywhere - free tiers included.

Embedding any episode or movie is one line (swap in your own instance URL):

<iframe src="https://your-instance/tv/105248/1/1"
        width="100%" height="100%"
        allow="autoplay; fullscreen; encrypted-media; picture-in-picture"
        allowfullscreen></iframe>

Routes: /tv/{tmdbId}/{season}/{episode}  and  /movie/{tmdbId}

Self-hosting in four steps

Full guide for Linux, Windows and macOS lives in the repo README.

Install Node 18+

apt, brew or winget - nothing else, no npm install, no build step.

Get the code

Clone or download the repo, then npm start from the folder.

Open the site

The homepage on /, the player at /tv/105248/1/1. Want the browse UI too? VERIDIUM=1 npm start puts it at /browse.

Put it online

Caddy in front for automatic HTTPS, or deploy to Render free tier - README has both paths.
